# Stargame – Sternen-Legespiel

Ein Legespiel für eine Person im Browser: Sieben farbige Sternteile (3–4 Sterne je Teil) werden in eine Form mit 26 Plätzen (Reihen zu 7/6/7/6) gelegt, bis kein Platz mehr frei ist.

## Spielen

`index.html` im Browser öffnen – es gibt keine weiteren Dateien oder Abhängigkeiten.

## Schwierigkeitsstufen

| Stufe   | Vorgabe                                          |
|---------|--------------------------------------------------|
| Starter | 4 Teile liegen fest, 3 sind zu legen             |
| Junior  | 3 Teile liegen fest, 4 sind zu legen             |
| Expert  | 2 Teile liegen fest, 5 sind zu legen             |
| Wizard  | nur 3 farbige Einzelsterne, alle 7 Teile legen   |

Jedes Rätsel wird zufällig erzeugt und hat genau eine Lösung. Teile lassen sich wie im echten Spiel nur drehen, nicht spiegeln.

## Bedienung

- Teil aufs Brett ziehen – es rastet ein, wo es passt; vom Brett wegziehen legt es zurück.
- Antippen wählt ein Teil aus, nochmal antippen dreht es (oder Taste `R`, Mausrad beim Ziehen).
- **Tipp** legt ein richtiges Teil, **Lösung** zeigt alles, **Zurücklegen** räumt das Brett ab.
